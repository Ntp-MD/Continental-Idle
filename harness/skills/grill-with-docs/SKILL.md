# Grill with Docs

_A relentless interview to sharpen a plan or design, which also creates docs (Decision Timeline entries and glossary terms) as we go._

> Adapted from `mattpocock/skills` (MIT, Copyright (c) 2026 Matt Pocock). Snapshot 2026-09-12; see `NOTICE.md`.

User-invoked: run only on the user's order (see the skills gate in `harness/HARNESS.md`). Compose two skills:

1. Run the **grilling** skill - read `skills/grilling/SKILL.md` and walk the interview.
2. Apply the **domain-modeling** skill as docs crystallize - read `skills/domain-modeling/SKILL.md`, and write the glossary terms and Decision Timeline entries inline as the interview settles them.
